About me

I am a software engineering student at Salahaddin University-Erbil. I like building things people actually use, and that means the whole stack: the page you click, the API behind it and the server it runs on. My biggest project so far is KurdType, a typing test made for Sorani Kurdish, which is live at kurdtype.online.

Kurdish is written right to left and most typing tools ignore it, so a lot of my work is about getting the small details right: fonts, keyboard layouts and text direction. I am looking for an internship where I can work on a real product with an experienced team and keep learning.

Most software treats Kurdish as an afterthought. I want a Kurdish speaker to open any app I build and feel it was made for them first.

How I build

The order I followed for KurdType, and the one I use for everything since.

  1. Agree the contract

    Write down every endpoint, request and error in an OpenAPI file before any code, so the website and the API never guess.

  2. Build the API

    Laravel, MySQL and Redis. The server recalculates every score, so the leaderboard can be trusted.

  3. Build the interface

    React and TypeScript, right to left from the first line, with fonts that render Kurdish properly.

  4. Ship and keep it running

    Deploy and backup scripts, Cloudflare in front, and live updates over WebSockets.
